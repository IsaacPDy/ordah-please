# V1-18 Pre-added members and optional account linking

Implemented 2026-10-06 after the user confirmed immediate group/session participation and preservation of memberships/history on linking.

## Changes

- Add member accepts only a name; it creates an ordinary unlinked product user.
- Existing group assignment and session participation work immediately.
- Link login account requires explicit selection of an already signed-in account by name/email. No automatic matching or mandatory assignment.
- The signed-in account retains its identity and existing data. The pre-added member's groups, history, votes, selections, lines, and operational ownership move atomically. Historical participant names and audit actors remain unchanged.
- Active roles combine without granting roles from removed memberships. Same-session duplicates and favorite-rank conflicts block linking without changing either record. The original member is archived after success.
- Admin authorization, same-origin checks, input validation, row locking, and same-transaction audit protect both actions. Native dialogs handle focus and prevent duplicate submissions.
