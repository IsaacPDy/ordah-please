# V1-11 Admin reference UI redesign

Implemented October 6, 2026, after the user approved applying the supplied member references to admin and retaining the sidebar.

## Changes

A scoped admin stylesheet applies the approved visual system to Overview, Users & permissions, Groups, Catalog/editing, Imports, Refresh queue, Access requests, Audit log, and portal dialogs. It provides a centered 1440px workspace, sticky sidebar/header, responsive cards and split panels, rounded fields/actions, contained horizontal table scrolling, and viewport-bounded dialogs. The group table has six columns; menu fields adapt when an image is absent; the import dropzone stays inside its card. Catalog navigation remains current on nested edit routes. Backend actions, access checks, providers, and product rules are unchanged.
