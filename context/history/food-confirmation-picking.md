# Food confirmation picking

Subtasks:

- Contracts: `FoodPickRequest` (`{kind:"favorite", favoriteId} | {kind:"declined"} | {kind:"clear"}`) with strict `parseFoodPickRequest` (`packages/contracts/src/orders/order-requests.ts`) — the agreed deviation from the ordering spec §API: `clear` backs the visible "Cancel pick" button; full `SubmitFoodResponseRequest` snapshots stay reserved for the later inline-menu batch
- Favorites repository: `note` exposed on `FavoriteItemRow`, `itemDescription`/`imageUrl` on `FavoritePageRow` (`packages/db/src/repositories/favorites.ts`)
- Orders repository: `upsertFoodResponse` (participant status + `food_selections` upsert + rewrite `order_lines` in sequence), `clearFoodResponse` (deletes selection/lines, resets participant to pending), `listOrderLines` (user- then sort-ordered) with `FoodResponseLineInput`/`UpsertFoodResponseInput`/`OrderLineRow`
- Orders service: `submitFoodResponse` (participants-only, favorites-only picking with server-expanded prices/names against the pinned menu version; stale or unavailable favorites → CONFLICT with recovery copy), `advanceFoodDeadline` (lazy close on first read past the deadline: rank-1 defaults materialized via the shared `expandFavoriteLines`, `resolveFoodDeadline` classification, `ready_for_handoff` only when everyone is accounted for; idempotent no-op otherwise), and `loadOrderDetail` extended with `viewerFavorites` (branch-filtered, rank-sorted) and `lines`
- Runtime + API: `POST /api/orders/[orderId]/food-response` through `executeRoute` with the trusted-mutation check; `loadOrderDetailView` advances a past-deadline food order before reading
- Web UI: `FoodPickerSection` client island (tap-to-select favorite cards with "#1 · ordered automatically if you don't pick", Order this!/Cancel pick/Not eating, locked read-only states, empty-favorites browse link) and the living order page food sections (picker for participants, "N of M ordered" for members, manager info banner + Participants checklist with "Ordered · N choice(s)", "Not eating", "Picked by the manager", "Picking…", and "Did not order anything" after the deadline)
