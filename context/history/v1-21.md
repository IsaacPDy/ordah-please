# V1-21 Group managers and admin membership cards

Completed 2026-10-06 after the user confirmed member management is admin-only.

## Changes

- Admin Groups links to a group detail page with member cards, Add people, manager appointment/demotion, and confirmed member removal. Existing pre-added people are eligible. Ownership stays protected; archived groups are read-only in the new flow.
- New role mutation verifies a live active admin and target, rejects archived groups and owner changes, updates the expected existing role only, and audits in the same transaction. Platform-admin status remains unchanged.
- Current group Managers have owner-equivalent session access, including active sessions they did not join, logging and food/session correction, completion/cancellation, and editing/deleting history. Both the editor page and mutation services check the assigned group. Ordinary members retain their participation scope.
- Group rename allows Owners and Managers. Membership, appointment, invitation issuance, and invite-link rotation require Platform Admin, including legacy access endpoints. Invite display is admin-only.
- No migration, provider switch, paid dependency, native UI change, or production data mutation.
