# V1-19 Mobile web icon

Completed 2026-10-06.

Replaced `apps/web/app/apple-icon.png` with the same supplied artwork used by the browser tab. Both PNG files match byte for byte, preserving the source framing. Native Android artwork is outside this change.

Before implementation, the live site at `https://ordah-please-web.vercel.app` already served the new browser icon, verified by SHA-256 against the local source. Its Apple icon metadata still referenced the previous 180 × 180 artwork. An old mobile browser icon despite the live server serving the new image is consistent with a cached phone icon; the phone itself was not inspected.

No application logic changed, so no new unit tests were needed. Existing iPhone Home Screen shortcuts may need to be recreated to refresh their saved artwork.
