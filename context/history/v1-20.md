# V1-20 History session date

Completed locally on October 6, 2026.

## Problem and behavior

Changing Session date saved `createdAt`, but finished/cancelled History still displayed and grouped by `completedAt`. Past sessions and group History now prefer the saved Session date. Database newest-first ordering and the pagination cursor both use `createdAt`, so month filters and older pages agree. Completion date remains independent; older summary shapes retain a completion-date display fallback.
