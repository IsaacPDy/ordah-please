# V1-13 Full-width browser shell

Implemented October 6, 2026, after the user identified the centered outer box as a general browser UI problem.

Removed the 1200px desktop member cap and 1440px admin cap, centered margins, and outer shell borders. Desktop member shell shadow is removed. The header/sidebar/content now fill the window with existing inner page padding. The desktop floating order action aligns 32px from the window edge. Phone member composition and intentionally bounded inner forms remain unchanged.

A signed-in Chrome layout pass verified member Home and social session at 1920px (shell/header width 1920, shell x=0, session sidebar x=32), admin at 1512px (shell width 1512, x=0), and mobile Groups at 393px (shell width 393). No document horizontal overflow was observed. No backend mutations were submitted. Evidence screenshot: `/private/tmp/full-width-qa/session-desktop.png`, private and not committed.

Production web build, affected CSS formatting and diff whitespace checks passed. No behavior tests were added for this CSS sizing change. Production deployment remains unverified.
