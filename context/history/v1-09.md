# V1-09 Faster page data loading

## Implemented

- Versioned Vercel configuration places web functions in Singapore (`sin1`), alongside the production Neon region confirmed by the user on 2026-10-01. Vercel's project root was verified live as `apps/web`; the previous live function region was `iad1`.
- All web auth and feature runtimes share one lazy pg pool per server instance. Standalone test/tool clients and transaction boundaries remain independent.
- Existing unchanged product identities load with active memberships in one read and perform no write. Missing identities provision through the atomic unique-key upsert; changed names synchronize only when needed, then permissions are read again.
- Better Auth sessions and auth users resolve in one SQL query through Drizzle relations. No cookie caching or shared private-data cache was introduced.
- Favorite cards and branch favorite lines each use one owned, scoped query. Empty favorites, complete combination lines, quantities, and notes are preserved; card previews pick the last item by sort order and item ID deterministically.
- No database migration or paid service change was needed.
